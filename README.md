### Projects

**[Windows Server 2019 Infrastructure Lab](https://github.com/keithmuronda/windows-server-2019-infrastructure-lab)**
A Windows Server 2019 domain built and hardened from scratch — Active Directory Domain
Services, DNS, DHCP, Group Policy, SMB file services, NTFS permissions, fine-grained
password policies and least-privilege access, with a client joined and policy
application verified.

**[Python Network Programming](https://github.com/keithmuronda/python-network-programming)**
Four socket services using only the standard library: a TCP inventory server with a JSON
wire protocol, a JSON file-persistence booking application, a TLS-encrypted channel with
OpenSSL certificate generation and hostname verification, and a multi-threaded file
transfer server with locked shared output and length-prefixed chunked transfers.

**[Multi-Model Database Design](https://github.com/keithmuronda/multi-model-database-design)**
One library domain modelled three ways — Oracle relational with constraints, views and a
PL/SQL procedure; MongoDB documents with aggregation pipelines and `$lookup`; and a Neo4j
graph where loan details live on the relationship rather than the nodes.
